# Економія лімітів

Діє в кожній задачі, якщо промпт прямо не каже інакше.

1. Субагенти (Agent/Task — рев'ю-агенти, Explore, Plan, general-purpose) не запускати. Виняток — лише перед злиттям гілки, коли задача завершена й відтестована на стенді: один раунд агентами за темою, мінімально достатній набір; на фікси — вузький раунд лише на нові коміти, доки раунд не дасть нових фіксів поведінки.
2. Figma: спершу get_metadata потрібного вузла; get_design_context — лише на найменший потрібний вузол (дочірній id знайти через get_metadata), не на екран чи сторінку цілком; get_screenshot — лише коли без нього неможливо.
3. Не перечитувати файли, вже прочитані в цій сесії, без причини; пошук — вузькими шаблонами; великі файли — з offset/limit; вивід команд обрізати (| head, | grep, | wc -l), не cat цілих файлів і логів.
4. Звіт — за розділом «Формат звіту» нижче.
5. Перевірки на стенді — одним скриптом за прогін, не повторювати без змін у коді; /loop і нагадування не ставити без потреби.

## Формат звіту

Звіт — лише підсумок, без ходу роботи й без коду. Порядок:
1. Статус одним рядком: зроблено / СТОП (яка умова і чому).
2. Коміти: хеш — одна фраза. Інваріант — одним рядком (SAME / що ні).
3. Відхилення від завдання — кожне з причиною (одне речення).
4. Перевірки: підсумок числом («38/38», «26 сторінок — 0 відмінностей»); таблиця — лише для провалів або коли промпт її прямо вимагає.
5. Рішення від власника — нумерований список питань, кожне з варіантами й рекомендацією.
6. Нові рішення / борги / питання — номери й суть одним рядком.

Код у звіті:
- не показувати код теми, JS, SCSS, docs — лише файли й що змінилось одним рядком;
- diff на погодження (bpr-core, AGENTS.md, процесні документи): до ~60 рядків — повністю; більше — файл у scratchpad (шлях) + перелік змін: нові функції й хуки, перевірки прав / nonce / SQL / екранування — ці рядки дослівно, решта — описом;
- таблиці звірки з Figma й редагованості — лише коли промпт їх вимагає;
- звіт рев'ю агентами: знахідки — одним рядком кожна (агент · рівень · суть · коміт / defer).

Довжина звіту — орієнтовно до 80 рядків.
